# Pathly Test Plan

## Mechanical test

1. Open the Pathly homepage.
2. Start an experiment.
3. Select an experiment.
4. Complete the experiment.
5. Submit the experience.
6. Review simulated AI feedback.
7. Complete the reflection.
8. View the next experiment suggestions.

## Expected result

The user can complete the full flow without the application crashing or losing the selected experiment.

## Persona test

A synthetic university student should be able to understand what to do on each screen without additional instructions.
